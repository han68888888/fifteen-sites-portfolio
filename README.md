# Portfolio — 15 Websites

A plain static index page listing fifteen websites: name, category, one-line description
and a link to each live site.

## Deploy to Netlify

No build step.

1. Netlify → *Add new site* → *Import an existing project* → select this repo.
2. Build command: **empty**.
3. Publish directory: **`.`**
4. Deploy.

`netlify.toml` already sets this.
