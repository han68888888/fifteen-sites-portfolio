Approach

How the set was kept genuinely distinct

No shared vocabulary

Every build was checked against the ones before it on six axes — palette family, type pairing, hero architecture, signature interaction, button treatment and corner language. A new site had to differ on at least four.

One idea per site

Each project is built around a single sentence — “the pause is the point”, “reps, not amenities”, “one breath per scroll”. The layout, copy and motion all answer to that one line.

Motion that means something

No decorative fades. Every scroll mechanic explains the business: a tower that builds, a breath that cycles, a barbell that completes a set, a roster that indexes.
